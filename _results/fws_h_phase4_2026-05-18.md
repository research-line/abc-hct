## FWS-h Untergrenze

```text
c_low := min(h_F_ratio / q)  =  0.1985
  Datenpunkt: (1, 31, 32),  q = 0.840,  ratio = 0.1667
```

**c_low ≈ 0.20** empirisch. Daraus q-Schranke:

```text
ratio ≤ 1/2  ⟹  c_low · q ≤ 1/2  ⟹  q ≤ 1/(2 c_low) = 2.52
```

Empirisch gibt FWS-h+Szpiro nur `q ≤ 2.52`. Das ist **schwächer** als
die abc-Vermutung (q ≤ 1+ε).

## Mathematische Interpretation

Für Frey-Kurven gilt rigoros (semistabil):
```text
log |Δ_min|  =  log 16 + 2 log(abc)
log N        ≈  log rad(abc)
```

Daher:
```text
h_F / log N  ≈  (log 16 + 2 log(abc)) / (12 log rad(abc))
             ≈  (2/12) · q(abc)         (für a≪b≈c)
             =  q / 6
```

mit `q(abc) := log(abc)/log rad(abc)`. Beachte: für Frey ist
`q(abc) = log(abc)/log rad(abc)` nicht identisch mit
`q(c) := log c / log rad(abc)` — sie unterscheiden sich um den
log(a·b)/log rad-Anteil.

**Das erklärt die lineare Regression mit Slope 1/6 ≈ 0.17 in der Theorie**
vs. 0.27 empirisch. Die Differenz kommt aus dem genauen Verhältnis
zwischen q und q(abc) sowie 2-adischen Korrekturen.

### Szpiro-Reformulierung in FWS-h-Sprache

Wenn FWS-h gilt mit `h_F/logN ≈ q/6`, dann:
```text
Szpiro: h_F/logN ≤ 1/2 + ε  ⟺  q/6 ≤ 1/2 + ε  ⟺  q ≤ 3 + ε
```

Aber die echte abc-Vermutung folgt aus Szpiro mit Frey-spezifischer
Übersetzung:
```text
Szpiro + Frey:  log|Δ| ≤ (6+ε) log N
              = 2 log(abc) ≤ (6+ε) log rad(abc)
              ⟹ log(abc)/log rad(abc) ≤ 3 + ε
              ⟹ 3·log c / log rad ≥ log(abc) / log rad     (weil a,b≤c)
              ⟹ q = log c / log rad ≤ 1 + ε  ✓
```

Also: **Szpiro ⟹ abc** über Frey-Algebra. FWS-h reformuliert Szpiro in
Faltings-Sprache, ohne neue Information zu liefern.

**Aber empirisch interessant**: die Linearität `h_F/logN ≈ q/6 + const`
ist eine **konkrete quantitative Aussage**, die in der Frey-Familie
universell zu gelten scheint.

## Was FWS-h NICHT leistet

1. **Kein neuer abc-Beweis**: FWS-h ist äquivalent zu Szpiro (asymptotisch).
2. **Keine super-lineare Verschärfung**: die Frey-Spezifizität gibt
   keinen schärferen Faktor als 1/6.
3. **Kein direkter Hebel auf c_low > 1/4**: empirisch c_low ≈ 0.20.

## Was FWS-h LEISTET

1. **Konkrete quantitative Form der Szpiro-Vermutung**: `h_F/logN ≈ q/6`
   als Frey-spezifische Reformulierung.
2. **Empirische Bestätigung der Linearität**: auf 104 Datenpunkten
   stabile Pearson-Korrelation 0.80.
3. **Identifikation des Ausreißers (ABCHome_2)**: das Tripel
   (121, 48234375, 48234496) ist arithmetisch atypisch — kleiner
   Konduktor relativ zu seiner Qualität.
4. **Klare Visualisierung der "Szpiro-Wand"**: 99% der Frey-Tripel
   liegen unter `h_F/logN = 1/2`.

## Bezug zu Bilanz nach Loop 324

Die Hoffnung "FWS-h liefert abc direkt" war zu stark. **FWS-h ist
empirisch sehr robust, aber asymptotisch nur Szpiro**. Das passt zur
Pattern-A-Lehre (`PATTERN_A_LESSON.md`): Eine Reformulierung in
neuer Sprache (Faltings statt Modulargrad) liefert oft Äquivalenz, nicht
Stärkung.

## Was als nächstes prüfbar wäre

1. **Echte Faltings-Höhe statt naiver Approximation**: mit
   archimedischer Korrektur. PARI hat `ellfaltings(E)` falls verfügbar.
   Erwartete Korrektur: ratio um Faktor 0.95-1.0, also kein dramatischer
   Effekt.

2. **Tripel mit q > 1.7**: schwer zu finden, müsste man systematischer
   suchen (Cohen-Lenstra-Heuristik o.ä.).

3. **Untergrenze c_low rigoros**: gibt es eine bewiesene
   universelle Untergrenze `h_F/logN ≥ c_low > 0`? Falls ja: c_low > 1/4
   würde abc beweisen.
