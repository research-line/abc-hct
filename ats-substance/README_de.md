Build: pdflatex -interaction=nonstopmode -halt-on-error -file-line-error für jede versionierte EN-/DE-TeX-Datei dreimal aus diesem Verzeichnis ausführen. Das Manifest bindet Quellen- und PDF-Bytes; Build-Zeitstempel können die Bytes neu erzeugter PDFs ändern.
